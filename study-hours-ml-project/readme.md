# Study Hours vs Marks Prediction using Machine Learning

## Project Overview

In this project, a machine learning model is used to predict the marks of a student based on the number of hours he or she studies for the exam.

The objective of this project is to show how machine learning concepts can be used to solve a real-life problem in the field of education.

---

## Problem Statement

The problem statement for this project is:

How does the study time impact the performance in the exam? The objective of this project is to model the relationship between the study time and the marks obtained in the exam using the historical data.

The problem statement for this machine learning project can be stated as:

**"If I study for some hours, what marks can I expect?"**

---

## Objective

The objective of this project is:

* To apply the fundamental machine learning concepts
* To develop a simple machine learning model
* To analyze the relationship between the study hours and the marks obtained in the exam
* To visualize the prediction model results

---

## Machine Learning Approach

The approach for this project is **Linear Regression**, a supervised learning algorithm used for predictions of continuous value types.

The relationship learned by the algorithm is as follows:

**Input:** Study Hours
**Output:** Exam Marks

The algorithm then makes predictions for new input values of study hours entered by the user.

## Project Workflow

1. Import required libraries
2. Create dataset for study hours and marks
3. Train a Linear Regression model
4. Ask the user to input study hours
5. Predict the marks using the trained model
6. Display prediction results
7. Visualize the relationship using a graph
